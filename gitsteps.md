# Git Initialization

## VS Code

```
1. Open the VS Code.
2. Click on **File** option from the Top-menu.
3. Click on **Open Folder** to open your own folder to work on
4. Click on **Terminal** option from top-menu.
5. Click on **New Terminal**.
    Note: Ensure that the terminal shows your folder name at the end and before this sign: >
```

## Terminal of VS Code

1. Run following command if your folder is new and has to be initialized for Git

```
git init
```

2. Run following commands to configure your name and email for Git:

```
git config user.name "Ahmed"
```

Press **Enter**.
Then run another command:

```
git config user.email "sample@sample.com"
```

Press **Enter**

## VS Code Sidebar

1. Click on the Branch icon saying **Source Control** on hover.
2. You will see an option for commit with Check icon and a message input.
   You can see your files, inside the current folder, under the **Changes** tab, below commit button.
3. If you are sure about those files, write a commit message and press **Commit** button.
4. Once done, you can see your commit in the **Graph** section of the Source Control.
